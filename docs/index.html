AnchorDesk

Your service desk, anchored to your data.

Local-first ticketing for MSPs and IT teams, with email-to-ticket, SLA automation, device context, RMM actions, a customer portal, append-only audit records, and authenticated agent workflows.

  • PostgreSQL stays the source of truth
  • Mobile-first ticket and device workflows
  • Docker, Kubernetes, and GHCR releases
  • MCP server for AI agents — tickets, checklists, notes, time, and search

Integrations, labeled honestly: IMAP/SMTP, netviz probes, and Tactical RMM are available; Jira sync is beta; ConnectWise, NinjaOne, and Datto are alpha.

ComFlow

Voicemail that arrives ready to act on.

A voicemail regulator — deliberately not an AI receptionist. It answers over SIP, transcribes and structures each message, puts everything in one review inbox, and turns the right calls into AnchorDesk tickets.

  • Bring your own SIP trunk
  • Pluggable speech and language providers
  • Single-team and multi-tenant modes
  • MCP endpoint with RBAC-scoped API keys

Try it before you wire it: stub telephony and AI providers are the default, so you can work the inbox end to end before pointing a SIP trunk or an API key at it.

Partner Center Bridge

Every customer tenant, one reconcile loop.

An ASP.NET Core API and React console in front of Microsoft Graph and the Partner Center API. A contract declares the desired state — starting with Win32 app templates — and the bridge reconciles every tenant on it, replacing repeat portal archaeology with reviewable, audited runs.

  • Stable: templated Win32 deploys, new-hire and offboarding provisioning, cross-tenant Find User
  • Beta: Diagnose → Fix → Verify workflows, mailbox repair, config snapshots, and an MCP server behind a human approval queue
  • Passkeys and TOTP for local accounts, or bring any OIDC provider
  • Two-way LDAP sync is planned — not built yet

NetViz

A free, open-source LAN scanner and network visualizer on a native Go scan engine. Devices stream in live as a table, a grouped graph, and a clickable hierarchy map. No agents, no accounts, no Nmap.

  • TCP-connect discovery of common LAN ports — no raw packets, drivers, or special privileges
  • Monitor mode re-scans on your interval and flags new, offline, and changed devices
  • Bundles netviz-cli and a headless netviz-probe that can feed AnchorDesk device inventory
  • Scan history stays in a local SQLite database; scan only networks you are authorized to scan
  • Windows and Linux archives carry SHA-256 checksums; the Windows binaries are Authenticode-signed
  • No prebuilt macOS download yet — on macOS it builds from source

SpoolSmith

Copy a working network-printer setup from one PC to another. Review a dry-run plan, apply it against a plan fingerprint, and it fails closed if the address now answers as a different device.

PS> spoolsmith copy "Accounting" acct.ssb
PS> spoolsmith apply acct.ssb --dry-run

Native Windows app and CLI, Authenticode-signed. --include-driver carries the driver package out of the driver store, and it exports a local Intune Win32 package.
